## How it works

`main.ts` (Node 22, standard library only) reads `entry.png`, checks it is a
whole PNG or JPEG of at most 1024×1024 pixels and at most 1 MiB, then copies it
to `/output/entry.png`. It draws nothing and fetches nothing, so both grader
runs write identical bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
